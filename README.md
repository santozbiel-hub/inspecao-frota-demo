# Inspeção de Frota

Checklists, fotos, observações, progresso semanal, histórico, permissões e sincronização offline.

O código da aplicação real, adaptado para portfólio, está em [`sistema/`](sistema/). Inclui telas, regras, autenticação, migrações e testes. A identidade da empresa, contatos, imagens identificáveis e registros operacionais não fazem parte desta cópia.

A prévia estática anterior na raiz é apenas uma demonstração simplificada, separada do sistema completo. Ela não comprova integração com banco nem representa todas as telas do sistema.

## Executar a aplicação completa
Consulte [sistema/README.md](sistema/README.md). Requer um projeto Supabase novo, suas próprias variáveis e usuários. Não existe conexão configurada com produção.

## Dados e reutilização
Dados de teste são fictícios. Substitua marca, catálogo, configurações e infraestrutura pelos de um novo projeto. As permissões originais foram mantidas. Não copie histórico privado ou dados de clientes.
